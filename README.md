# English 33 Days

Sep 29 to Oct 31, 2026. 60 minutes every day.

Goals: IELTS basics and daily English speaking.

## Daily 60 minutes

1. Words (10 min): 5 new words from the Oxford Dictionary. One sentence for each.
2. Speak (15 min): say the sentences aloud. Record 1 minute.
3. Listen (15 min): BBC Learning English or British Council.
4. Grammar (10 min): today's grammar point.
5. Write (10 min): 4-5 sentences about today's topic.

## Every day

1. Copy `logs/day-01.md` format. Fill today's log.
2. Add 5 words to `vocabulary.md`.
3. Change ⬜ to ✅ in the table below.
4. Commit: `day-XX: log + 5 new words`

One commit per day.
